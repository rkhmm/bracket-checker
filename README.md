# Bracket Checker

**Автор:** Хамматова Радмила, группа M3115

**IDE:** Visual Studio Code

Лабораторная работа №3 «Создание плагина».

## Описание

Расширение для VS Code, которое проверяет парность скобок `()`, `[]`, `{}`
в открытом файле. Алгоритм основан на структуре данных «стек».

## Возможности

- Находит лишние закрывающие скобки.
- Находит скобки разных типов, которые не подходят друг к другу, например `( ]`.
- Находит незакрытые открывающие скобки.
- Игнорирует скобки внутри строк (`"..."`), символов (`'...'`) и комментариев (`//` и `/* */`).
- Подчёркивает ошибки в редакторе и показывает пояснение при наведении мыши.
- Показывает количество найденных ошибок в строке состояния.

## Как пользоваться

1. Открой файл с кодом.
2. Нажми `Cmd+Shift+P` (на Windows и Linux `Ctrl+Shift+P`).
3. Выбери команду **«Проверить скобки»**.

## Установка и запуск

1. Склонировать репозиторий: `git clone <адрес репозитория>`
2. Открыть папку в VS Code и выполнить в терминале `npm install`
3. Нажать `F5`: откроется окно Extension Development Host с работающим расширением.

## Структура проекта

- `src/bracketChecker.ts` — логика проверки (стек).
- `src/extension.ts` — подключение расширения к VS Code, подчёркивания и строка состояния.
- `package.json` — описание расширения и его команды.
